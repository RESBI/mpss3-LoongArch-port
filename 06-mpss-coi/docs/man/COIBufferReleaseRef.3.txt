COIBUFFERRELEASEREF(3)
======================
:doctype: manpage

NAME
----
COIBufferReleaseRef - Removes a reference to the memory of a buffer.

SYNOPSIS
--------
*#include <COIBuffer_sink.h>*

*COIRESULT COIBufferReleaseRef(void* \*'in_pBuffer'*);*

DESCRIPTION
-----------
The *COIBufferReleaseRef*() call removes a reference to the memory of a buffer. The
memory of the buffer will be eligible for being freed on the device when the following
conditions are met: the run function that delivered the buffer returns, and the number
of calls to COIBufferReleaseRef() matches the number of calls to COIBufferAddRef().


NOTES
-----
When a buffer is addref'ed it is assumed that it is in use and all
other operations on that buffer waits for ReleaseRef() to happen.
So you cannot pass the addref'ed buffer's handle to RunFunction
that calls ReleaseRef(). This is a circular dependency and will
cause a deadlock. Buffer's pointer (buffer's sink side
address/pointer which is different than source side BUFFER
handle) needs to be stored somewhere to retrieve it later to use in
ReleaseRef.

On successful return, COI_SUCCESS is returned.

RETURN VALUE
------------
Upon successful completion, *COIBufferReleaseRef*() returns COI_SUCCESS indicating
that buffer ref count was successfully decremented; otherwise
COI_INVALID_POINTER: if the buffer pointer was invalid,
COI_INVALID_HANDLE: if the buffer did not have COIBufferAddRef() previously
called on it.
