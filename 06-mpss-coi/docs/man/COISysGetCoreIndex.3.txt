COISYSGETCOREINDEX(3)
=====================
:doctype: manpage

NAME
----
COISysGetCoreIndex - Returns the index of the core on which the caller
 	             is running.

SYNOPSIS
--------
*#include <COISysInfo_common.h>*

uint32_t COISysGetCoreIndex(void);

DESCRIPTION
-----------
The *COISysGetCoreIndex*() call returns the index of the core on which the
caller is running. The indexes of neighboring cores will differ by a value of one and are
within the range zero through COISysGetCoreCount()-1.

RETURN VALUE
------------
Upon successful completion, *COISysGetCoreIndex*() call returns the index of
the core on which the caller is running; otherwise returns ((uint32_t)-1)
if there was an error loading processor info.
