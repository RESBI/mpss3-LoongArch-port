# CHANGELOG — User-space SCIF library (02-libscif)

 This file records **functional updates** to this package. Each entry is one functional update: what changed, why, and how it was verified. Entries run **oldest first — the newest update is at the bottom**.

---

## 2026-10-04 — Build system integration

- **Added** Two Makefiles per package: `Makefile.mpss` is the upstream original, `Makefile` is this release's wrapper (builds the package and installs it where MPSS expects to find it). Both `DESTDIR` and `PREFIX` are supported for staged installs.
- **Fixed** Infinite recursion in the wrapper Makefile: the `build` target originally ran `$(MAKE) …` without `-f Makefile.mpss`, so it kept re-reading itself — in testing it recursed down to `make[7]` and produced a 420,000-line, 31 MB log. Every invocation now names `-f Makefile.mpss` explicitly (or uses `-C <subdir>`).

## 2026-10-05 — Builds, installs and works on loongarch64

- **Added** `libscif.so` and its headers (`scif.h`, `scif_ioctl.h`) build on loongarch64 and install into `$(PREFIX)/lib64` and `$(PREFIX)/include`; linking with `-lscif` works out of the box.
- **Added** Public ABI names are preserved: exported symbols carry version names (such as `SCIF_1.0`), generated by `gen-symver-map` from `00-build-tools` (on non-x86 hosts these are emitted as link-time aliases instead). Binaries built on x86 and code that resolves symbols by version name keep working unchanged.
- **Recorded** The library is a **pure pass-through**: `scif_register` copies the length, offset, protection bits and flags supplied by the caller straight into the ioctl structure, and the library contains no page-size constant. Registration granularity is therefore decided by the caller and the driver — which is why, for callers, registering in multiples of 4096 bytes is the correct thing to do.
- **Verified** On real hardware: SCIF session setup, 64-byte and 26,496-byte message round trips (0 bytes mismatched), card-initiated messages and bidirectional fences. Covered by `tests/t3_scif_comm.sh`.
