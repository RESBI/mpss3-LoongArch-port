myoArenaDestroy(3)
==================
:doctype: manpage

NAME
----
myoArenaDestroy - Destroy an arena. As a result, the arena can not be
referred any more.




SYNOPSIS
--------
*#include <myo.h>*

*extern MyoError myoArenaDestroy(MyoArena in_Arena)*

DESCRIPTION
-----------
 parameter: in_Arena Arena handle returned by previous call to
myoArenaCreate.



RETURN VALUE
------------

MYO_SUCCESS; or
an error number to indicate the error.
