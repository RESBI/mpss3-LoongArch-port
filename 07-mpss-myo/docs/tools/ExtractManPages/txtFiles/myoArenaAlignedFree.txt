myoArenaAlignedFree(3)
======================
:doctype: manpage

NAME
----
myoArenaAlignedFree - Frees the memory space allocated by myoArenaAlignedMalloc
to the specified arena.




SYNOPSIS
--------
*#include <myo.h>*

*extern void myoArenaAlignedFree(MyoArena in_Arena, void *in_pPtr)*

DESCRIPTION
-----------
 parameter: in_Arena Arena handle returned by previous call to
myoArenaCreate.


 parameter: in_pPtr The start address of the specified memory space,
which must be returned by myoArenaAlignedMalloc.



RETURN VALUE
------------
void
