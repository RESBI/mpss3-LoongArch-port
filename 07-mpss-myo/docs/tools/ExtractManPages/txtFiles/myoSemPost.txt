myoSemPost(3)
=============
:doctype: manpage

NAME
----
myoSemPost - Increments (unlocks) the semaphore. If the semaphore value
becomes greater than zero, one blocked myoSemWait call will be
notified to return.




SYNOPSIS
--------
*#include <myo.h>*

*extern MyoError myoSemPost(MyoSem in_Sem)*

DESCRIPTION
-----------
 parameter: in_Sem the semaphore handle returned by myoSemCreate.



RETURN VALUE
------------

MYO_SUCCESS; or
an error number to indicate the error.
