myoArenaRelease(3)
==================
:doctype: manpage

NAME
----
myoArenaRelease - myoArenaRelease is the sync point for "OURS" arena with
"Release Consistency". myoArenaRelease is used to flush all prior
stores of "OURS" arena to be globally visible.




SYNOPSIS
--------
*#include <myo.h>*

*extern MyoError myoArenaRelease(MyoArena in_Arena)*

DESCRIPTION
-----------
 parameter: in_Arena Arena handle returned by previous call to
myoArenaCreate.



RETURN VALUE
------------

MYO_SUCCESS; or
an error number to indicate the error.
