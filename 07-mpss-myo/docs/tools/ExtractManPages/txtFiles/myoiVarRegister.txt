myoiVarRegister(3)
==================
:doctype: manpage

NAME
----
myoiVarRegister - Register shared variables. Call it on all sides in myoiUserInit.
On host side, make sure calling it after allocating shared memory for
the shared variables by calling myoSharedMalloc.




SYNOPSIS
--------
*#include <myoimpl.h>*

*extern MyoError myoiVarRegister(void *in_pAddrOfLocalPtrToShared, char *in_pSVarName)*

DESCRIPTION
-----------
 parameter: in_pAddrOfLocalPtrToShared the address assigned by the compiler
for the shared variable, which is the address of a local pointer,
pointing to shared memory space.


 parameter: in_pSVarName name of shared variable.



RETURN VALUE
------------

MYO_SUCCESS; or
an error number to indicate the error.
