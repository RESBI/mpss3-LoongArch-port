myoSharedFree(3)
================
:doctype: manpage

NAME
----
myoSharedFree - Frees the memory space allocated by myoArenaMalloc to the
default arena.




SYNOPSIS
--------
*#include <myo.h>*

*extern void  myoSharedFree(void *in_pPtr)*

DESCRIPTION
-----------
 parameter: in_pPtr The start address of the specified memory space,
which must be retured by myoSharedMalloc.



RETURN VALUE
------------
void
