myoSemTryWait(3)
================
:doctype: manpage

NAME
----
myoSemTryWait - Try to lock semaphore. myoSemTryWait is the same as
myoSemAcquire, except that if the decrement cannot be immediately
performed, then the call returns instead of blocking.




SYNOPSIS
--------
*#include <myo.h>*

*extern MyoError myoSemTryWait(MyoSem in_Sem)*

DESCRIPTION
-----------
 parameter: in_Sem the semaphore handle returned by myoSemCreate.



RETURN VALUE
------------

MYO_SUCCESS; or
an error number to indicate the error.
